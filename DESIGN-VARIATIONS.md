## 🔄 How to Switch Between Designs

### Option 1: Link Different CSS in HTML
Update your `index.html` to link to the CSS file of your choice:

```html
<!-- Currently using Variation 1 (Luxury Minimal) -->
<link rel="stylesheet" href="css/styles-v1-luxury-minimal.css" />

<!-- To switch to Variation 2 (Modern Bold), change to: -->
<link rel="stylesheet" href="css/styles-v2-modern-bold.css" />
```

### Option 2: Use Design Switcher
Open `design-switcher.html` to see a visual comparison and explanation of all variations.
