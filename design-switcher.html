📋 Current Variation

Variation 1: Luxury Minimal
Dark charcoal (#2c2c2c) with gold accents (#b8860b). Elegant serif (Cormorant Garamond) typography. Clean, minimal design with generous whitespace. Perfect for upscale wedding and event planners.

🔄 How to Use

Click any button above to instantly switch between design variations. Go to index.html to see the full website with your chosen design. To make a design permanent, copy the CSS file from css/ folder and use it as your main stylesheet.

✅ Implementation Steps

  1. Browse all 5 designs using the buttons above
  2. Choose your favorite variation
  3. Copy the corresponding CSS file name (e.g., styles-v2-modern-bold.css)
  4. Update your index.html to link to that CSS file
  5. Go live with your new design!
